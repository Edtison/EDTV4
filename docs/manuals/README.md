# EDTV4 Operating Manuals

The public operating documentation is maintained directly in the repository so that procedures and technical references can be reviewed together with the firmware and hardware files.

## Public manuals

- 🇩🇪 [`EDTV4_Bedienungsanleitung_DE.md`](EDTV4_Bedienungsanleitung_DE.md) - Deutsche Bedienungsanleitung
- 🇬🇧 [`EDTV4_Operating_Manual_EN.md`](EDTV4_Operating_Manual_EN.md) - English operating manual

Both manuals use the current `printer.cfg` as the source for configured firmware limits. Internal network addresses, login information and personal student identifiers from earlier internal documents are intentionally excluded.

## Source material

The earlier internal PDF manuals are not tracked in the public repository. If they need to be retained locally for archival/reference purposes, place them under:

```text
docs/manuals/_source/
```

This directory is excluded by `.gitignore`.
