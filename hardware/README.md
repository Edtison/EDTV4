# EDTV4 Hardware

This directory contains the public mechanical design package and bill of materials for EDTV4.

## Contents

- [`cad/`](cad/) – neutral assembly, manufacturing drawings and component exports
- [`bom/`](bom/) – public bill of materials without prices or project totals

## CAD package

The CAD package is intentionally organized by manufacturing group rather than by the original development folder structure.

Available groups:

- acrylic panels,
- electrical enclosure parts,
- milled components,
- sheet-metal parts,
- final neutral STEP assembly.

See [`cad/README.md`](cad/README.md).

## Bill of materials

The public BOM contains quantities, component descriptions, manufacturer/article information and supplier links where available. Project prices and total costs are intentionally excluded.

See [`bom/README.md`](bom/README.md).
