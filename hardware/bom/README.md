# Bill of Materials

The public EDTV4 BOM is provided in two formats:

- `EDTV4_BOM.xlsx` - spreadsheet version
- `EDTV4_BOM.csv` - text/table version suitable for direct viewing on GitHub

The public BOM contains component identification, quantities and supplier information but **no prices or project cost totals**.

Small manufacturing-specific part lists that belong directly to drawing packages remain in the corresponding CAD folders.
